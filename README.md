# Financial Data Management & Reporting System

A lightweight financial management and reporting system designed to streamline payment collection, payment verification, expense tracking, automated receipt generation, and financial reporting.

## Overview

The system combines Google Sheets, Google Apps Script, Google Drive, Google Docs, and a web-based interface to create a structured financial workflow for organizations.

## Key Features

* Member payment submission
* Payment proof upload
* Payment verification workflow
* Financial approval and rejection
* Automated receipt generation after approval
* Expense recording
* Income and expense tracking
* Automated balance calculation
* Category-based financial analysis
* Interactive financial dashboard
* Role-based access control
* Financial reporting

## Workflow

```text
Member
   ↓
Payment Submission
   ↓
Payment Proof
   ↓
Pending Verification
   ↓
Financial Officer
   ↓
Approve / Reject
   ↓
Receipt Generation
   ↓
Financial Records
   ↓
Dashboard & Reporting
```

## User Roles

### Member

* Submit payments
* Upload payment proof
* Provide payment information

### Financial Officer

* Review pending payments
* Verify payment evidence
* Approve or reject payments
* Record expenses
* Monitor financial reports

### Administrator

* Manage system configuration
* Manage users and permissions
* Access financial reports
* Manage system parameters
